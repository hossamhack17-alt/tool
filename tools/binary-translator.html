Binary Translator

Convert text to binary and binary to text. 8-bit, offline.

What is Binary Translator?

Computers store text as binary: A = 01000001, B = 01000010 in ASCII. Binary translator converts text to 8-bit binary strings and back, useful for learning how computers encode characters, for low-level programming, and for CS education.

Used by students learning ASCII, by developers debugging binary protocols. Runs locally, no upload. Converts via charCodeAt and toString(2).

How to use

  1. Enter text, click Text → Binary → get 8-bit groups.
  2. Enter binary groups separated by space, click Binary → Text.

Real example

Text "Hi" → H=72 → 01001000, i=105 → 01101001 → "01001000 01101001". Binary "01001000 01101001" → "Hi".

How it works

Text to binary: for each char, charCodeAt → toString(2).padStart(8,'0'). Binary to text: split by space, parseInt(c,2) → String.fromCharCode. Only handles 8-bit ASCII, not full Unicode. For Unicode, need UTF-8 encoding.

FAQ

Supports Arabic? No, 8-bit ASCII only. Arabic needs UTF-8 binary (more than 8 bits per char).
