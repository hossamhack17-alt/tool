Slug Generator

Convert text to SEO-friendly URL slugs. Offline.

What is Slug Generator?

Blog title "Best Tools 2025: How I Built My Site!" needs URL "/best-tools-2025-how-i-built-my-site". Slug is URL-friendly version: lowercase, hyphens instead of spaces, no special chars, good for SEO and readability. This generator converts any title to slug offline.

Used by bloggers, WordPress users, developers creating routes. Runs locally, no upload.

How to use

  1. Paste title.
  2. Click Generate Slug.
  3. Copy slug for URL.

Real example

Input: "Hello World! This is my Blog Post" → Output: "hello-world-this-is-my-blog-post".

How it works

Lowercase → remove non-alphanumeric except space and hyphen via regex [^a-z0-9\s-] → replace whitespace with hyphen → collapse multiple hyphens. O(n). Does not transliterate Arabic — for Arabic slugs, keep Arabic or use separate transliteration.

When to use?

  • Create SEO URLs for blog
  • Generate route names

FAQ

Handles Arabic? Current version removes Arabic, keep English for slug, or manually keep Arabic if your CMS supports Arabic URLs.
