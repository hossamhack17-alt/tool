HTML Minifier

Minify HTML — remove comments and extra whitespace. Shows savings.

What is HTML Minifier?

Production websites should serve minified HTML: remove comments, collapse whitespace, to reduce file size 20-30% and improve load time and PageSpeed. Minifier takes pretty-printed HTML with indentation and comments and outputs compact single-line version that browsers parse identically.

Used before deploying to Cloudflare Pages, for email HTML, for embedding HTML in JS. Runs locally, no upload, so private HTML with internal data stays private.

How to use

  1. Paste HTML.
  2. Click Minify.
  3. Copy minified output, see savings %.

Real example

Input: <div> Hello World </div> <!-- comment --> → Output: <div> Hello World </div> — comment removed, spaces collapsed, saved 30%.

How it works

Regex: //g removes HTML comments. /\s+/g collapses whitespace to single space. Trim removes leading/trailing. O(n). Does not minify CSS/JS inside, only HTML structure. For aggressive minification, use html-minifier library.

When to use?

  • Production deploy
  • Email HTML

FAQ

Does it break HTML? No, whitespace collapse is safe for most HTML, but may affect <pre> — avoid minifying inside <pre>.
