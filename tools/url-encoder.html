URL Encoder & Decoder

Encode and decode URLs safely. Handles Arabic and spaces.

What is URL Encoder?

You want to share link https://example.com/search?q=hello world & Arabic مرحبا. Spaces and Arabic are not allowed raw in URL — they must be percent-encoded as %20 and %D9%85%D8%B1%D8%AD%D8%A8%D8%A7. URL Encoder converts unsafe characters to %XX format using encodeURIComponent, and Decoder reverses via decodeURIComponent.

Essential for developers passing query parameters, for SEO when creating slugs with Arabic, and for API calls. Runs locally, no data sent.

How to use

  1. Paste URL or text with spaces/Arabic.
  2. Click Encode to get % encoding.
  3. Click Decode to revert.

Real example

Input: "hello world" → Encode → "hello%20world". Input Arabic "مرحبا" → " %D9%85%D8%B1%D8%AD%D8%A8%D8%A7".

How it works

encodeURIComponent encodes all except A-Z a-z 0-9 - _ . ! ~ * ' ( ). It converts UTF-8 bytes to % hex. decodeURIComponent reverses. Implementation in browser engine, O(n).

When to use / NOT

Use for query params, Arabic URLs. Do NOT use for Base64 — different encoding.

FAQ

Difference between encodeURI and encodeURIComponent? encodeURIComponent encodes more characters, safer for params.
