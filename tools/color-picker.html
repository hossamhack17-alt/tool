Color Picker & HEX to RGB Converter

Pick colors and convert HEX ↔ RGB. Visual, offline.

What is Color Picker?

Designer sees color #6366f1 in Figma and needs RGB 99,102,241 for CSS. Or developer has RGB and needs HEX for Tailwind config. Color Picker lets you pick visually and converts instantly. Shows preview box.

Used for web design, CSS, Tailwind, Flutter. Runs locally, no upload. Converts via parseInt hex to decimal and toString(16) back.

How to use

  1. Pick color via color input or type HEX.
  2. RGB updates automatically.
  3. Type RGB to get HEX.

Real example

#ff0000 → RGB 255,0,0 red. RGB 0,128,0 → HEX #008000 green.

How it works

HEX #RRGGBB → R = parseInt(RR,16), etc. RGB → HEX via toString(16).padStart(2,'0'). O(1).

FAQ

Supports alpha? No, only opaque colors.
