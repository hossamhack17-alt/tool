CSV to SQL Insert Converter

Convert CSV to SQL INSERT statements. Private, runs in browser.

What is CSV to SQL Converter?

You exported a spreadsheet with 200 customers: id, name, email, price. You need to import it into MySQL. Writing 200 INSERT statements by hand is error-prone. This converter takes CSV where first row is column names and produces INSERT statements you can run directly in phpMyAdmin, DBeaver or psql.

Most converters upload your CSV to a server, which is risky if it contains customer emails or internal prices. This tool runs 100% client-side: it splits text by newlines and commas using JavaScript, escapes single quotes by doubling them (''), and builds INSERT strings locally. Your data never leaves your device. You can verify by checking Network tab — no upload.

How to use

  1. Export sheet as CSV or copy from Excel.
  2. Paste into box, ensure first line is header: id,name,price
  3. Enter table name, e.g., customers.
  4. Click Convert, then Copy SQL and run in your SQL client.

Real example

Input CSV:

id,name,email
1,Ahmed,ahmed@example.com
2,Sara,sara@example.com

Output SQL:

INSERT INTO customers (id, name, email) VALUES ('1', 'Ahmed', 'ahmed@example.com');
INSERT INTO customers (id, name, email) VALUES ('2', 'Sara', 'sara@example.com');

How it works

Logic: split input by newline → headers = first line split by comma → for each remaining line, split by comma, trim, escape ' as '' → build INSERT. Dialect option currently changes quoting style but both MySQL and PostgreSQL accept standard INSERT. Complexity O(rows). No external library.

When to use?

  • Migrating Excel product list to MySQL.
  • Seeding test database with 1000 rows.
  • Converting Google Sheets export to PostgreSQL.

When NOT to use?

If CSV contains commas inside quoted fields like "Ahmed, Jr.", simple split by comma will break. For such CSV, use a proper CSV parser or pre-clean data. Also, for very large files (100k+ rows), browser may slow — split file.

Common errors

1. Column count mismatch: Row has 2 values but header has 3. Check empty commas.

2. Special characters: Arabic is fine, but ensure file is UTF-8.

3. Single quotes in data: O'Brien becomes 'O''Brien' automatically — correct for SQL.

FAQ

Is my CSV uploaded? No. Conversion happens via JavaScript split() locally.

Does it handle data types? Currently all values are quoted as text. For integers, you can remove quotes manually if needed.

Can I convert to UPDATE? Not yet, only INSERT.
