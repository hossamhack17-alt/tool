What is BMR Calculator?

BMR (Basal Metabolic Rate) is calories your body burns at rest to keep breathing, heart beating, brain working. If you know BMR, you can estimate total daily needs by multiplying with activity factor. This calculator uses Mifflin-St Jeor equation, which is considered most accurate for non-athletes by many dietitians.

Formula: Men: 10*weight(kg) + 6.25*height(cm) -5*age(y) +5. Women: 10*W +6.25*H -5*A -161. Source: Mifflin et al., American Journal of Clinical Nutrition 1990. This tool runs locally, no health data sent. Informational only, not medical advice.

How to use

  1. Select sex, enter age, weight kg, height cm.
  2. Click Calculate. BMR in kcal/day appears.

Real example

Male, 25y, 70kg, 175cm → 10*70=700, 6.25*175=1093.75, -5*25=-125, +5 → 700+1093.75-125+5=1673.75 kcal/day at rest.

How it works

Implements Mifflin-St Jeor directly in JavaScript. No server. Rounding to nearest kcal. Does not include activity factor — multiply BMR by 1.2 sedentary, 1.375 light, 1.55 moderate per common practice (consult professional).

When to use / NOT to use

Use for diet planning estimate. Do NOT use as medical diagnosis, does not account for muscle, illness, pregnancy. See Disclaimer.

Common errors

Using lbs instead of kg gives wrong BMR. Convert first.

FAQ

Is BMR same as TDEE? No, TDEE = BMR * activity factor.

Stores data? No, local.
