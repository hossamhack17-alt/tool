Base64 Encoder & Decoder

Encode text to Base64 and decode back. Unicode safe, offline.

What is Base64 Encoder?

Email systems originally only handled ASCII. If you wanted to send an image or Arabic text, you needed to encode binary into 64 safe characters: A-Z, a-z, 0-9, +, /. Base64 does exactly that. Developers today use Base64 to embed small images in CSS as data URIs, store binary in JSON, or encode Basic Auth headers.

This tool uses btoa/atob with Unicode handling via TextEncoder: encodeURIComponent → unescape → btoa. This avoids broken Arabic that naive btoa causes. Everything runs locally, so API keys or tokens you encode never leave your browser.

How to use

  1. Paste text to encode or Base64 string to decode.
  2. Click Encode or Decode.
  3. Copy output.

Real example

Input: "Hello" → Base64: "SGVsbG8=" → Decode back → "Hello". Arabic: "مرحبا" → Base64: "2YXYsdit2Kc=" → decode returns same Arabic.

How it works

btoa converts binary string to Base64. To support Unicode, we first encodeURIComponent (UTF-8 percent encoding), then unescape to binary, then btoa. Decoding reverses: atob → escape → decodeURIComponent. No server.

When to use?

  • Embed image in HTML/CSS as data URI.
  • Encode token for Authorization header.
  • Store binary in JSON.

When NOT to use?

Base64 is NOT encryption. Anyone can decode. Do not use to hide passwords. It also increases size by ~33%, so not for large files.

Common errors

Invalid character error: Input contains characters outside Base64 alphabet. Check for spaces or line breaks.

FAQ

Is it secure? No, encoding only, not encryption.

Stores data? No, local.
