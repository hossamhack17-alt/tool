Case Converter

Convert text to UPPER, lower, Title Case instantly.

What is Case Converter?

You typed entire paragraph with CAPS LOCK on: "HELLO WORLD". Or you need Title Case for blog headline: "How To Build Tools". Manually retyping is tedious. Case Converter changes capitalization instantly using JavaScript string methods toUpperCase, toLowerCase, and custom Title Case logic.

Used by writers fixing caps mistakes, programmers converting constants, SEO editors formatting headings. Runs locally, no upload. Supports Unicode but Arabic has no case, stays same.

How to use

  1. Paste text.
  2. Click desired case.
  3. Copy result.

Real example

Input: "hello world" → UPPERCASE → "HELLO WORLD". Input: "HELLO WORLD" → lowercase → "hello world". Input: "hello world" → Title Case → "Hello World".

How it works

toUpperCase and toLowerCase use Unicode case mapping. Title Case: lowercases whole string, splits by space, capitalizes first char of each word. Sentence case: lowercases then capitalizes first char.

When to use?

  • Fix caps lock mistakes
  • Format blog titles
  • Convert code constants

FAQ

Supports Arabic? Arabic has no uppercase/lowercase, remains same.
