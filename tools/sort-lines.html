Sort Lines Alphabetically

Sort text lines A-Z, Z-A, by length. Offline.

What is Sort Lines?

You have list of 200 city names unsorted, need alphabetical for dropdown. Or keyword list you want sorted by length to find long-tail. Sort Lines sorts text lines using JavaScript Array.sort which is stable and uses Unicode code point order.

A-Z uses default string comparison (case-sensitive, uppercase before lowercase in ASCII). Z-A reverses. By length sorts shortest first, useful for finding shortest keywords. Runs locally, no upload.

How to use

  1. Paste lines.
  2. Click A→Z, Z→A, or By Length.
  3. Copy sorted result.

Real example

Input: banana, apple, orange → A→Z → apple, banana, orange. By Length → apple (5), banana (6), orange (6) — apple first.

How it works

Split by newline → Array.sort() → join by newline. For length, sort((a,b)=>a.length-b.length). O(n log n).

FAQ

Case sensitive? Yes, uppercase sorts before lowercase. Convert case first if needed via Case Converter.
