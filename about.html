Why was IsraelPost created?

Most online converters require uploading CSV with customer emails, JSON with API keys, or images with private data. For a small business handling customer data, uploading to an unknown server is risky and may violate privacy expectations. IsraelPost was started in 2024 to build local-first alternatives.

Every tool is designed to work 100% in the browser tab using vanilla JavaScript, Web Crypto API (SubtleCrypto for hashing, crypto.randomUUID for UUIDs, crypto.getRandomValues for passwords), FileReader API for file checksums, and Canvas for QR codes. You can verify by opening DevTools → Network → no file content is POSTed when you use any tool. You can even disconnect internet after page loads and tools still work.

How are tools developed?

  1. Problem selection: We pick a real problem reported by users or observed in forums, e.g., "I need to convert 5000-line CSV to SQL without uploading customer emails" or "I need to format minified JSON from an API to debug".
  2. Prototype: Build minimal prototype with vanilla JS, no heavy libraries. For hashing we use SubtleCrypto, for QR we use qrcodejs CDN, for color we use native color input.
  3. UI clarity: User must instantly know: what tool does, where to paste, where to click, where result appears, how to copy. We place tool at top, explanation below, so content does not bury tool.
  4. Testing: Checklist per tool: valid input, empty input, malformed input, very large input (20k+ lines or 50k chars), special characters, Arabic text, emoji, mobile viewport (no horizontal overflow), copy button works, reset works, error message clear and not technical jargon.
  5. Documentation: For each tool we write specific content: what it is, how to use step by step, real example Input→Processing→Output, how it works (formula, algorithm, browser API), when to use, when NOT to use (especially for financial/health), common errors, FAQ specific to that tool, internal links to related tools, sources where applicable (NHS, CDC, Investopedia).

Testing methodology for calculators

BMI: Formula BMI = weight kg / (height m)², categories per CDC and NHS (Underweight <18.5, Normal 18.5–24.9, Overweight 25–29.9, Obese ≥30). Tested with 70kg/175cm → 22.9 Normal.

BMR: Mifflin-St Jeor: Men 10*W +6.25*H -5*A +5, Women 10*W +6.25*H -5*A -161, source American Journal of Clinical Nutrition 1990. Tested male 70kg/175cm/25y → 1673 kcal.

Loan EMI: EMI = P*R*(1+R)^N / ((1+R)^N -1) where R = annual/12/100, N = years*12, source Investopedia amortization. Tested P=10000, 8%, 5y → $202.76.

All calculators include disclaimer that results are educational/estimates, not medical or financial advice.
