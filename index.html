Tools that work without uploading your files.

Most online converters ask you to upload CSV, JSON or images containing private data. IsraelPost builds alternatives that run 100% in your browser tab using JavaScript and Web Crypto API. Open DevTools → Network to verify: no file content is POSTed.

Built by Ahmed Bream in 2024 for students and small businesses who need everyday utilities without expensive software. Every tool is tested with valid, empty, invalid and large inputs before publishing. Last reviewed: August 2026.

Tool Categories

Developer Tools

JSON Formatter validates and beautifies minified API responses, shows exact syntax error location using JSON.parse. Base64 Encoder handles Unicode via TextEncoder. URL Encoder uses encodeURIComponent for Arabic and spaces. UUID Generator uses crypto.randomUUID (CSPRNG). HTML Minifier removes comments and collapses whitespace to improve load time. Markdown to HTML converts # ** * links to HTML tags. Hash Verifier uses SubtleCrypto for SHA-256 file checksums offline.

Text & Data Tools

Word Counter counts words via whitespace split, characters, sentences and reading time at 200 wpm, supports Arabic. Case Converter fixes caps lock via toUpperCase/toLowerCase and Title Case via custom logic. Slug Generator converts title to SEO-friendly slug: lowercases, removes special chars, replaces spaces with hyphens. Remove Duplicates uses Set to deduplicate email lists while preserving order. Sort Lines sorts A-Z, Z-A, by length using Array.sort. CSV to SQL converts spreadsheet rows to INSERT statements without uploading customer emails, escaping single quotes by doubling.

Calculators

BMI = kg/m² with categories per CDC/NHS, includes disclaimer that it does not account for muscle mass and is not medical advice. BMR uses Mifflin-St Jeor: Men 10*W+6.25*H-5*A+5, Women -161, source American Journal of Clinical Nutrition 1990. Age Calculator computes exact years/months/days accounting for leap years via Date API. Loan EMI = P*R*(1+R)^N/((1+R)^N-1) per Investopedia, estimate only, excludes fees. Discount and Percentage compute savings and final price, Percentage handles X% of Y and X is what % of Y. Unit Price compares cost per kg/liter to find true cheapest.
